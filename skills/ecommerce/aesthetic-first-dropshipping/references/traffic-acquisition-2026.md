# Traffic Acquisition Playbook — DailyFinds 2026

## Channel Roles

| Channel | Role in funnel | Cadence / budget |
|---|---|---|
| Pinterest organic | Discovery + compounding traffic | 5-15 Pins/day, 3-5 fresh/week |
| Instagram Reels | Trust validation + shopping path | Daily editorial + 2-4 reels/week |
| Reddit organic | Zero-cost cold-start niche traffic | 1-2 quality posts/week in desk/maker subs |
| Pinterest Ads | Proven-Pin amplification | $10-20/day after organic CTR > 1% |
| TikTok Shop | Creator-driven impulse discovery | Phase 1: creator content; later Shop Ads if ROAS > 2.5 |
| Email/SMS | LTV + repeat | Activated after first paid order |

## Pinterest execution standard

- Pin size: 1000×1500px 2:3; avoid > 1000×2100px truncation.
- Title first 50-60 chars must carry the buyer keyword.
- Description answers "what will I find when I click" — no hashtag spam.
- Boards should be keyword themes, not brand promos.
- Use Rich Pins after claiming dailyfindusa.com.
- UTM everything in analytics.

## TikTok Shop execution standard

- 15s structure: 0-3s hook visual → 3-8s problem/reset → 8-12s 2 benefits + CTA → 12-15s incentive.
- Affiliate tiers: micro 10k-100k = 12-15%, mid 100k-1M = 8-12%, macro custom.
- Pay commissions weekly; ship samples with camera-ready unboxing kit.
- Do not treat Shop like Amazon. Algorithm rewards engagement and creator relationships, not price.

## Instagram execution standard

- 60% value / 30% product / 10% brand narrative.
- Reels → Stories → Shop is the 2026 conversion path.
- "Premium Realism" visual style: high-res lived-in shots, not staged studio.

## Reddit execution standard

- Subs: r/desksetup, r/buyitforlife, r/Japandi, r/WorkFromHome.
- Format: Before/after, "What I use for...", Setup tour.
- No links in post body on first engagement; win comments first.
- One genuine post per sub per week max to avoid spam shadow.

## X/Twitter execution standard

- Not primary discovery for desk goods.
- Use for founder narrative + community relationship, not store traffic.
- Repurpose high-performing Reddit/Instagram content as threads.

## Budget split when paid spend starts

Start only after organic proof in each channel:
- 50% paid media
- 25% email/SMS
- 25% organic content
